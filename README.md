# 今日打卡（双版本：快船主版 + 凌波丽版）

一个简洁的每日习惯打卡网页，纯本地使用，含两个主题版本：index.html 是 LA Clippers 主版本（你自己用）；ei/index.html 是独立的凌波丽版（淡蓝短发+红眼+白色驾驶服，含桌宠，给朋友试玩）。

## 两个版本
- 快船主版：https://zycgod-opop.github.io/habit-checkin/
- 凌波丽版（含桌宠）：https://zycgod-opop.github.io/habit-checkin/rei/

## 使用方法
- 双击打开 `index.html`（或用浏览器打开），无需联网、无需安装。
- 顶部可切换两个视图：
  - **今日**：添加/管理习惯，每天完成一项点一下打勾，顶部显示今日完成进度。
  - **统计**：按年/月查看每个习惯的当月小日历——实心 = 已完成，空心 = 未完成，
    白色圆点 = 当天写过备注，高亮框 = 今天。点击某个「未完成」的日子，可写下当天为什么没做。
- 每天零点自动开始新的一天；前一天的打卡不会带到今天。
- **每日心得**：今日页底部每天可写一段心得，边写边自动保存；点「查看往期心得」可回看以前写过的（只读）。
- **版式切换**：今日页右上角「双栏」可一键把 打卡/心得 左右并排（宽屏生效），点「单栏」切回上下排列；选择会被记住，手机上自动保持上下排列。
- **归档习惯**：今日列表每行右侧「暂停」按钮可把习惯归档（保留全部历史）；页面下方「已归档」区可随时恢复或永久删除。
- **拖动排序**：长按（手机）或按住拖动（电脑）习惯行即可调整顺序，自动保存。
- **回顾统计**：统计页每个习惯显示 本月/本周/连续/最长 天数；点击日历上「已完成」的日期可打开当天回顾（各习惯状态 + 未打卡备注 + 当天心得）。
- **安装成桌面 App**：用 Chrome/Edge 打开 `http://127.0.0.1:8000/`，点地址栏的「安装」图标即可装成桌面应用（安装需本机服务保持开启；手机端完整安装需 HTTPS 托管，可之后再配）。
- **饮食升级**：可切换日期记录历史；可设每日热量/蛋白目标并显示达标进度与「还差 X」；近 7 天热量/蛋白柱图与日均；体重记录 + 7 天趋势。
- **每月小结报告**：统计页点「生成月报」，自动汇总当月习惯完成率/未打卡原因、训练天数动作数与推拉腿分布、饮食记录天数日均与体重变化、心得篇数与最近一篇；支持复制文本/下载 .txt。
- **教练知识包**：健身 → 教练 → 教练知识包 可导入文稿/字幕（.txt/.srt），本地自动提炼要点并接入教练分析与对话；已登记「谭成义 · 增肌减脂」知识包（来源视频见 skills/tan-chengyi-coach/SKILL.md）。
- **账号云同步（默认：本机服务，免注册）**：页脚「账号 / 同步」→ 保持「本机服务」→ 用任意邮箱+密码注册/登录 → 数据自动同步到这台电脑的服务文件 `.habit_sync_db.json`；手机连同一 Wi-Fi 打开 `http://192.168.8.8:8000/` 登录同一账号即可多端合并。此模式需通过 `http://127.0.0.1:8000` 打开使用。
- **账号云同步（可选：Supabase）**：在「账号 / 同步」里切到 Supabase → 填项目 URL + anon key（先在 SQL Editor 执行 `supabase.sql`）→ 注册/登录 → 云端合并；断网可用，联网自动补同步。
- **健身·饮食**：第三栏「健身 → 饮食」内置约 60 种常见食物/品牌营养（每 100g 热量/蛋白/碳水/脂肪，页面标注为参考值）；支持搜索、输入克数自动换算、自建品牌食物、可选「联网搜索」公开品牌库（需外网）。
- **健身·训练**：「训练」按 **推/拉/腿三分化** 排周计划（周一~周日以 1~7 数字格展示，可改当天组别）；勾选动作并记录重量×次数，可自建动作。
- **训练心得**：每天可评 1~5 星感受并写心得；当天做过的动作以**罗马数字（I. II. III.…）**列出，可对单个动作补备注；底部自动汇总 本周/本月/今年 训练天数、动作数与平均星级。

## 数据说明
- 数据保存在**本浏览器**的 localStorage 中，不会上传到任何服务器。
- 建议定期点底部「导出数据」保存备份文件；换浏览器或清理浏览器数据后，可用「导入数据」恢复。
- 导出/导入会自动包含每日打卡记录、未打卡备注和每日心得；旧版（无备注/心得字段）备份也能正常导入。
- 删除习惯会同时清除它过去的所有打卡记录和备注。

## 说明
- 统计页不支持补卡（只能记当天的勾），未打卡的原因通过备注记录。
- 数据格式：`{ habits, records, notes, journal, foods, movements, dietLog: {日期: 食物条目}, workouts: {日期: 动作条目}, trainDays: {日期: {stars, note, moves}} }`（健身新字段旧版备份导入自动补空）

## 桌面版与提醒、AI（v4）
- **桌面一键启动**：双击项目里的 启动今日打卡.vbs（已创建桌面快捷方式「今日打卡」）；停止今日打卡.vbs 停止服务；开启开机自启.vbs / 关闭开机自启.vbs 管理开机启动（已默认创建开机启动快捷方式）。
- 桌面版自带 untime/node.exe（88MB，已加入 .gitignore），不依赖 Codex 缓存。
- **提醒系统**：今日页「提醒设置」可设训练/饮食/心得/未打卡提醒时间；浏览器通知需点「开启浏览器通知」授权；提醒在页面或桌面窗口开着时生效。
- **AI 教练（可选）**：健身 → 教练 → AI 教练，填入 OpenAI 兼容 Base/模型/Key 并启用；Key 只存本机 localStorage，不随导出/仓库；本地服务通过 /api/ai 代理调用；失败自动回退本地规则教练。
